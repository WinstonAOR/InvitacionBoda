---

## 🛠️ Tecnologías Utilizadas

Este proyecto está construido con un enfoque moderno y modular sin necesidad de herramientas de compilación pesadas:

* **HTML5:** Estructura semántica de la página.
* **CSS3 (`css/style.css`):** Estilos personalizados y diseño adaptable.
* **Tailwind CSS (CDN):** Estilizado rápido y responsivo.
* **JavaScript (`js/script.js`):** Lógica de control de invitados mediante tokens seguros en la URL.
* **GitHub Pages:** Alojamiento y despliegue continuo.
